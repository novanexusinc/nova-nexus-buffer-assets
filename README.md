# nova-nexus-buffer-assets

Temporary public hosting for Nova Nexus production packet v3.6 feed images, used only so the Buffer CLI can attach artwork to drafts. These 38 PNGs are the November 24-December 23, 2026 publishing slides.

This repository is not a product codebase. It exists because the Mac had no already-authenticated Drive sharing CLI, and Buffer's CLI requires publicly fetchable image URLs.

After the corresponding Buffer drafts are reviewed and the posts are published, make this repository private or delete it.
